# 🧠 Encore OS Secondary Brain Server

24/7 Unlimited Free Server for Encore OS Android App & Telegram.

## 🚀 1-Click Deployment on Render (100% Free)

1. Go to [Render.com](https://render.com) -> Click **New +** -> **Web Service**.
2. Select your GitHub Repository (`encore-secondary-brain-server`).
3. Add these **Environment Variables**:
   - `TELEGRAM_BOT_TOKEN`: (Your Bot Token from @BotFather)
   - `TELEGRAM_CHAT_ID`: (Your Private Telegram Chat/Channel ID)
   - `GROQ_API_KEY`: (Your API Key from console.groq.com)
4. Click **Create Web Service**!
